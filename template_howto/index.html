  1. 01

    Save your own copy first

    File → Save As → "Nursing Handbook 2027-2028"
    Before you type anything

    Type first and save later and you overwrite the master. Check the title bar: it should no longer say "Template".

  2. 02

    Learn the click

    Click once anywhere in a paragraph, then click a style name in the gallery above. That's it. No need to highlight the text first.

  3. 03

    Fill in the cover page

    Every line already has its style. You are only typing over the bracketed words. Hover a number to see which line is which.

  4. 04

    Build the page structure

    This is one page of the template showing every style you'll use in the body. Work down the pins.

    What to call each level

    Heading 1 is a section, Heading 2 a subsection, Heading 3 a topic, Heading 4 a detail. Four words, four levels, always in that order.

    Not a Word section break

    Word has a feature called Insert Section Break. It is unrelated, and you never need it. A section here means a Heading 1 and nothing more.

    Expect this

    Applying Heading 1 jumps the text to a fresh page. That's deliberate — every section starts its own page. Don't undo it, and never add a page break of your own.

  5. 05

    Write the prose

    Everything ordinary is Body Text. Press Enter and you stay in it.

    The one that breaks documents

    Never press Enter to make space. Every gap is built into the styles. Blank paragraphs get read aloud as nothing by screen readers, and they drift when anyone edits above them.

  6. 06

    Add lists

    Apply Body Text, then click the bullet or number button in the Paragraph group. Tab nests a line deeper, Shift+Tab brings it back.

    Numbers only when order matters. Otherwise bullets.

  7. 07

    Flag what students can't miss

    Apply Callout — pin 5 in the picture above. Save it for deadlines, safety rules, and grounds for dismissal. A callout on every page is wallpaper.

  8. 08

    Add a table

    1. Insert → Table.
    2. Top row: apply Table Heading. It turns purple.
    3. Other cells: apply Table Text.
    4. Select the top row → Table Layout → Repeat Header Rows.
    5. Add a Caption line underneath.
    Step 4 is not optional

    It carries headings across page breaks and tells a screen reader which row is the header. Without it, a listener hears numbers with nothing attached.

  9. 09

    Add images and describe them

    Insert → Pictures. Right-click → View Alt Text, write what it conveys. Add a Caption underneath.

    Flowcharts need more

    Your clinical absence and performance algorithms carry decision logic no single sentence holds. Write the steps into the body text nearby too.

  10. 10

    Build the table of contents

    Click the placeholder on page 2, press F9. Word reads your headings and writes this:

    Do it last, then again

    Word rebuilds the whole list every update, so never fix an entry by hand — your edit is discarded. Page numbers only settle once the text is final.

  11. 11

    Clean up

    1. Delete the last page, "Template Usage — Delete This Page".
    2. Delete every purple italic instruction line (pin 2 in step 4).
    3. Ctrl+F, search [. Every hit is an unfilled placeholder. Repeat until none.
    4. File → Info → Properties → Title. Screen readers announce it first.
  12. 12

    Run the accessibility check

    Review → Check Accessibility

    Clear every item it lists, then update the contents once more with F9. You're done.

Never

Five things that break the template

  1. Changing font, size, or color by hand. If a style looks wrong, fix the style — for every document, not one paragraph.
  2. Pressing Enter to make space. Spacing lives in the styles.
  3. A page break — or a Word section break — before a Heading 1. It already starts a page. You'd get a blank one.
  4. Text in gold. Far too faint to read. Rules and borders only.
  5. Color alone carrying meaning. Pair it with words.
